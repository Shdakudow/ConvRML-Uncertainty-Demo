How to interpret this comparison

Reconstruction images are clipped to [0,1] for display; metrics and error maps use unclipped predictions. Per-image metrics appear below each model. Coverage is the fraction of RGB channel values inside calibrated intervals, not a guarantee that each whole image is covered.

Samples are saved inference results. The buttons select another test example; they do not train or run models in the browser. Quantile curves and interpolated quantile images are intentionally omitted from this comparison.
