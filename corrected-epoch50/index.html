How endpoints are calibrated

The reconstruction stays unchanged. Each model starts with native bounds L₀ and U₀ around prediction μ. On 2,048 independent calibration images, separate lower and upper factors are fitted:

LB = clip(μ − sL × max(μ − L₀, 0.000001), 0, 1)
UB = clip(μ + sU × max(U₀ − μ, 0.000001), 0, 1)

Im2im learns its endpoints directly. Ensemble uses mean ± 1.64485 × standard deviation, including predicted noise variance and between-model variance. MC dropout uses the same Gaussian approximation with variance across 30 stochastic passes. RCPS allocates 5% miscoverage and δ=0.025 to each tail; overall target α=0.10 and confidence budget δ=0.05. This targets average pixel/channel coverage, not 90% for every image.

How to interpret this comparison

Examples marked Clipped [0,1] use clipped reconstructions and calibrated bounds for all image metrics, maps and pixel values. Validation curves and displayed test metrics use clipping to [0,1]. Per-image metrics appear below each model. Coverage is the fraction of RGB channel values inside calibrated intervals, not a guarantee that each whole image is covered.

Samples are saved inference results. The buttons select another test example; they do not train or run models in the browser. Quantile curves and interpolated quantile images are intentionally omitted from this comparison.
