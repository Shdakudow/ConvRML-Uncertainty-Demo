How to read these numbers

Higher PSNR and SSIM mean better reconstruction. MAE is average absolute error. Coverage is the fraction of ground-truth RGB values inside the bounds; the target is 90%. Compare interval widths at similar coverage: narrower alone does not mean better.

These averages use the full test set, rather than only the image shown above. LPIPS measures perceptual difference; lower is better. Pearson and Spearman compare unsmoothed RGB-average uncertainty width with absolute error within each image, then average across images. Download full-test analysis.

About these curves

PSNR and SSIM use all 2,000 validation images. Width and coverage use all 2,000 test images, with calibration on 3,000 separate images. Focused vertical axes emphasize differences. Calibration failures remain gaps in the calibrated line; hollow diamonds show native intervals without successful calibration.

Calibration details & exact epoch values

QUTCC learns a quantile function using uniformly sampled q and pinball loss, with 48 FiLM sites. Calibration selects a global lower and upper q. Im2im trains end to end with center MSE and two pinball endpoints, then fits separate lower and upper scale factors.

Both use the paper-style adjusted empirical tail-risk procedure, rather than Hoeffding–Bentkus RCPS. No δ confidence guarantee is claimed. For α = 0.10 and 3,000 calibration images, the per-tail budget is (0.10 − 0.90 / 3000) / 2 = 0.04985.

Calibration uses unclipped outputs. Displayed predictions, bounds and metrics are clipped to [0,1]. This can reduce width and increase coverage at boundary values. Endpoints are never reordered. RGB-average maps share a fixed 0–0.35 intensity scale; larger values saturate.

Each image can have coverage above or below 90%. A native q = 0.05 / 0.95 reference is explicitly uncalibrated and does not establish 90% coverage.

Training settings & data

RGB images are 270 × 480. The split is 17,999 training, 2,000 validation, 2,000 test and 3,000 calibration pairs. Internal padding is excluded from losses and metrics. Corrupted inputs use the reviewed PNG files; targets remain unchanged.

Cropping and patch rotations are sensor-domain stress tests. Scrambling and the held-out noise families appear in the dataset-review controls and are excluded from this training mixture.

The first test examples follow manifest order without quality selection. The browser displays saved float32 inference results; it does not run the models.
