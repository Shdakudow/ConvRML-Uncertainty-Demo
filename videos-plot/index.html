How this is measured

Brightness is each model’s own reconstructed RGB mean, not measured light intensity. Width is the RGB mean of calibrated upper − lower, with predictions and bounds clipped to [0,1]. Both curves use the same finite, uncrossed pixels. A near-zero coefficient can hide a curved relationship; these curves do not measure uncertainty accuracy.
