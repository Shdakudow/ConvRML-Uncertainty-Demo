Experiment details

Browse 50 test scenes in the original split order. Overall scores use all 2,000 test scenes; examples were not chosen by quality.

The original input is the lensless sensor image. The target is the sharp scene used to judge reconstruction. Changes affect the sensor image only. clip keeps values between 0 and 1.

Generalized training chose clean input or one of nine modification families with 10% probability each. Exposure used a global gain of 0.50 or 1.50, each with 5% probability overall. Masks and pixel patterns simulate a different sensor per image.

Each model is calibrated once on the same separate 3,000-scene mixture, aiming for 90% overall coverage. This is empirical calibration, with no population guarantee. Coverage for an individual modification can differ. Any failed calibration is marked explicitly.

Absolute-error maps show mean RGB |reconstruction − ground truth| on a shared 0–1 color scale.

PSNR and SSIM: higher is better. MAE: lower is better. Coverage is the fraction of target RGB values inside the interval. Width is the mean interval size. Crossing is the fraction with lower bound above upper bound. Predictions and bounds are clipped to [0, 1] for scores; crossed bounds are never sorted. Scores use full-precision outputs before display images are rounded to 8 bits.
